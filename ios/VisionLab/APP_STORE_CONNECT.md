# First video

Start with a 30-second clip and the prompt “What happens in this video? Describe the important actions in chronological order with approximate timestamps.” Use Qwen3-VL-Plus for the initial baseline.

Qwen3-VL-Plus accepts video files from 2 seconds to 1 hour. The direct base64 route used here has a separate encoded-video limit below 10 MB, so the app prepares the full clip as MP4 targeting no more than 7 MB before encoding. A longer duration limit does not guarantee any long file will fit this route.

The 32B and 8B Instruct choices use a 20-minute limit. The server's default video sampling is 2 frames/second; brief or subtle actions can fall between sampled frames. The first response tests what the model can actually infer, not merely whether the upload succeeded. See [Alibaba video limits](https://www.alibabacloud.com/help/en/model-studio/vision).
